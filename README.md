# Parallel Programming

Репозиторий содержит лабораторные работы по дисциплине «Параллельное программирование», выполненные на C++ с использованием современных возможностей языка и инструментов параллельных вычислений.

## Содержание

| Лабораторная работа | Описание | Технологии |
|---|---|---|
| [Lab1](./Lab1/) | Последовательное умножение квадратных матриц | C++23, Python, NumPy |
| [Lab2](./Lab2/) | Параллельное умножение квадратных матриц с исследованием производительности | C++23, OpenMP, Python, NumPy, Matplotlib |

## Lab1 — Последовательное умножение матриц

Программа выполняет умножение двух квадратных матриц и сохраняет результирующую матрицу в файл.

В рамках работы:
- реализовано последовательное умножение матриц;
- проведены эксперименты для размеров от 200 × 200 до 2000 × 2000;
- измерено время выполнения;
- построен график производительности;
- выполнена независимая проверка результатов с помощью Python и NumPy.

**Результат проверки:** 6 из 6 экспериментов пройдены успешно.

Подробнее: [Lab1/README.md](./Lab1/README.md).

## Lab2 — Параллельное умножение матриц

Программа выполняет умножение квадратных матриц с использованием OpenMP и позволяет исследовать влияние количества потоков на время выполнения.

В рамках работы:
- реализовано параллельное умножение матриц;
- проведены эксперименты для размеров от 200 × 200 до 2000 × 2000;
- исследовано выполнение с 1, 2, 4 и 8 потоками;
- измерены время выполнения и ускорение;
- построены графики производительности и ускорения;
- выполнена проверка результатов с помощью Python и NumPy.

**Результат проверки:** 24 из 24 экспериментов пройдены успешно.

Графики экспериментов:
- [Время выполнения](./Lab2/performance.png)
- [Ускорение](./Lab2/speedup.png)

Подробнее: [Lab2/README.md](./Lab2/README.md).
