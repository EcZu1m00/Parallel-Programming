# Лабораторная работа №2 — OpenMP

Параллельное умножение квадратных матриц на C++23 с использованием OpenMP.

## План работы

- Реализовать параллельное умножение матриц.
- Провести эксперименты для размеров 200, 400, 800, 1200, 1600 и 2000.
- Сравнить время выполнения при 1, 2, 4 и 8 потоках.
- Проверить корректность вычислений с помощью Python и NumPy.
- Построить графики производительности и ускорения.
